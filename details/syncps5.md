# SyncPS5

Syncthing running on a jailbroken PS5 as an ELF payload service.

## Features

- Syncthing file synchronization on PS5
- Continuous file sync between PS5 and other devices
- Runs as a background ELF payload

## Usage

1. Load the payload on your PS5
2. Configure Syncthing folders through the web interface
3. Files will sync automatically between your devices
