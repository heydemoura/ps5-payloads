# PS5 LocalSend

Native LocalSend protocol payload for PlayStation 5.

## Features

- LocalSend protocol implementation for PS5
- Browser-based dashboard for file management
- Send and receive files wirelessly between devices

## Usage

1. Load the payload on your PS5
2. Open the dashboard URL shown on screen
3. Use any LocalSend-compatible app to send/receive files
